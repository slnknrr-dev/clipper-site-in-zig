## JavaScript 2003 года: улучшение, а не основа

### Что было

JavaScript 1.5 в Netscape и Mozilla и JScript в IE реализовывали ECMAScript 3 (1999): функции, объекты, регулярные выражения, исключения. Модель документа — DOM Level 1 (1998): `getElementById`, `getElementsByTagName`, создание и вставка элементов. В IE5 и старше был ещё собственный `document.all`, в Netscape 4 — `document.layers`.

Событий было немного: `onclick`, `onsubmit`, `onload`, `onmouseover`. Событие `oncontextmenu` — правая кнопка мыши — появилось в IE5 и поддерживалось Mozilla.

И была вещь, о которой мало кто знал: `XMLHttpRequest`. Он появился в IE5 (1999) как объект ActiveX и в Mozilla 1.0 (2002) как встроенный объект. Слово «AJAX» придумают только в 2005 году. До того запросы из страницы делали редко и почти всегда через скрытый фрейм.

### Правило эпохи: всё работает без скрипта

Хороший сайт 2003 года не зависел от JavaScript. Скрипт добавлял удобство — подсказку, проверку поля, раскрывающийся список, — но каждое действие можно было сделать и без него. Это называли постепенным улучшением.

### Скрипт Клиппера

Во всём Клиппере один скрипт — контекстное меню на странице чтения для цитат и закладок. Вот его первые строки:

```
function cmEl(id) {
  return document.getElementById ? document.getElementById(id) : document.all[id];
}
```

`getElementById`, если он есть, иначе `document.all` для старого IE. Дальше — `oncontextmenu` на тексте книги: выделил фрагмент, нажал правую кнопку — открылось меню сайта «Цитата» и «Закладка». Shift и правая кнопка — обычное меню браузера.

И под текстом — форма «Отметить фрагмент», которая делает то же самое без скрипта. Без мыши, без JavaScript, в Lynx — цитату всё равно можно сделать.

### Почему Клиппер не использует XMLHttpRequest

Можно было бы отправлять цитату без перезагрузки страницы. Но тогда:

- у сервера появился бы второй вход для той же операции — ответ данными, а не страницей;
- у страницы появилось бы состояние, которого нет в адресе: «цитата отправлена, но страница не обновлена»;
- поведение сайта зависело бы от того, выполнился ли скрипт.

Каждый пункт делает сервер умнее (книга 0, ось «возможности против простоты»). Клиппер выбирает перезагрузку: одна операция — один путь — один адрес результата.

### Скрипт и сервер

Для сервера правило «работает без скрипта» означает простую вещь: каждое действие — это форма или ссылка, а значит, обычный запрос, который сервер умеет обрабатывать. Скрипт может только помочь пользователю заполнить форму. Сервер никогда не доверяет тому, что сделал скрипт, и никогда от него не зависит.

### Цена

Сайт без запросов из страницы не может обновляться сам: новые сообщения форума видны после перезагрузки. Для форума 2003 года это было нормой, для чата — нет. Клиппер — не чат.

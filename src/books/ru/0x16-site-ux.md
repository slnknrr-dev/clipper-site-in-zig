# Часть VI. Сайт

## Сайт глазами посетителя

Прежде чем разбирать код, стоит пройти по сайту так, как по нему ходит человек. Эта часть — о том, что Клиппер умеет и как это выглядит со стороны. Всё описанное можно открыть прямо сейчас: адреса в тексте настоящие.

### Адрес — это интерфейс

Главное в интерфейсе Клиппера — строка адреса. У каждой вещи на сайте есть короткий постоянный адрес из буквы и номера, и по нему понятно, что откроется.

| адрес | что откроется |
| /p/N | стихи, верлибры, авторская песня; /p/-N — песня с аккордами и нотами |
| /b/N | книга; /b/-N — серия книг |
| /b/N/K | страница K книги N |
| /q/N | сразу читать книгу N |
| /c/N | цитаты человека; /c/-N — цитаты персонажа |
| /d/N | черновик; /d/-N — статья |
| /f/N | форум; /f/имя — анонимная доска |
| /v/N | запись: аудиокнига или исполнение; /v/-N — чтец или исполнитель |
| /u/N | участник; /u/-N — автор; /u/0 — администратор |
| /s | поиск |
| /e | встраивание на другие сайты |

Знак номера различает родственное. Книга и серия книг — обе про книги, поэтому обе живут под буквой b. Человек и придуманный им персонаж — оба говорят цитатами, поэтому оба под буквой c. Так схема остаётся короткой: одиннадцать букв на весь сайт.

Номер ноль особый. `/b/0` — эта книга. `/u/0` — встроенный администратор, через которого сайт настраивают. Остальные нулевые адреса не открываются.

Страница `/help` показывает всю схему одной таблицей, и это не случайность: сайт, устройство которого помещается в таблицу, не нуждается в путеводителе.

### Что видит гость

Главная страница — это сводка по включённым разделам: последние книги, последние стихи, свежие черновики, форумы и цитата дня. Какие разделы есть на сайте, решает тот, кто его запускает (об этом ниже, «Разделы»), и главная собирается только из них. Гость может читать всё открытое ему, искать, скачивать книги и писать на анонимных досках. Чтобы комментировать, вести черновики и выделять цитаты, нужна учётная запись.

Поиск один, на странице `/s`: он ищет по названиям, аннотациям, стихам и, пока библиотека невелика, по полному тексту книг. Ответ — одна таблица: что найдено, как называется, чьё.

## Чтение, цитаты и закладки

### Страница чтения

Книга читается постранично: `/b/N/1`, `/b/N/2` и так далее. Страница чтения — это глава или её часть, если глава длинная. Сверху и снизу — листание, сбоку — оглавление, в котором видно, где вы сейчас. Адрес страницы постоянен: его можно сохранить, переслать, поставить в закладки браузера.

У каждого абзаца есть якорь: `/b/0/1#p3` — третий абзац первой страницы этой книги. На него можно сослаться.

### Цитата начинается в книге

В Клиппере нельзя написать цитату руками. Её можно только выделить в книге. Это решение интерфейса, у которого есть причина: цитата без источника — это утверждение, что кто-то что-то сказал. Цитата, сделанная из текста, сама себе доказательство: она хранит книгу, страницу, абзац и ведёт обратно к месту, откуда взята.

Как это делается. На странице чтения выделите фрагмент внутри одного абзаца и нажмите правую кнопку мыши. Вместо меню браузера появится меню сайта с двумя пунктами: «Закладка с примечанием» и «Цитата». Обычное меню браузера остаётся доступным через Shift и правую кнопку. Если скрипты выключены или мыши нет, под текстом есть форма «Отметить фрагмент», а на телефоне — кнопка «Отметить выделенное».

- **Закладка** личная. Её видите только вы, на странице `/bookmarks`, вместе со своим примечанием. Это способ вернуться.
- **Цитата** публичная. Она появляется в разделе цитат и подсвечивается в тексте книги для всех.

Так же цитату делают из стиха, песни и статьи: выделить в тексте и выбрать «Цитата» (закладки — только у книг). Цитата приписывается автору стиха или статьи и ведёт обратно к своему абзацу или куплету.

### Чьи это слова

Цитата приписывается либо автору книги, либо персонажу. Слова про «самый скверный городишко из всех приморских городов России» написал Лермонтов, но говорит их Печорин. Клиппер различает эти два случая, и это редкая для библиотек аккуратность.

Персонажа заводят заранее, на странице цитат. Он принадлежит автору и может быть привязан к одной книге, к нескольким или ни к одной: тогда он считается персонажем всего, что автор написал. Онегин — персонаж Пушкина, даже если самого романа в библиотеке нет. Номера персонажей отрицательные: `/c/-2`.

Страницу цитат можно сузить прямо адресом: `?op=` — начало цитаты, `?ed=` — конец, `?sz=` — не длиннее стольких предложений.

## Свои тексты: черновики, стихи, книги

### Черновик

Участник с правом писать ведёт черновики на `/d`. Черновик — рабочий текст: его можно править сколько угодно. У него есть метки и дата.

Дальше у черновика два пути, и оба в одну сторону.

- Черновик можно перенести в стихи: он получает адрес `/p/N` и больше не меняется.
- Несколько черновиков можно собрать в книгу: каждый становится главой, книга получает адрес `/b/N`, и на её странице написано, из каких черновиков она собрана.

После переноса исходный черновик остаётся, но только для чтения. Это тоже решение, а не ограничение: опубликованное не переписывают задним числом. На него уже могли сослаться, из него уже могли взять цитату.

Статья — черновик с отрицательным номером, `/d/-N`. Это текст о сайте, о книгах, о чём угодно: блог участника.

Черновик и статью можно удалить — автору, сотруднику и `/u/0`. Если черновик уже стал стихом или главой книги, опубликованное остаётся, а пропадает только след: отметка «собрана из черновиков». Как будто его сразу выложили от этого имени.

### Стихи и песни от имени автора

Стих Тютчева выкладывают не через черновик: страница `/p/new` принимает стих или песню от имени любого автора. Автор выбирается из людей сайта или вписывается по имени, и новый человек — с годами жизни — заводится сам, как при выкладывании книги. Кто выложил, хранится отдельно и написано на странице: «Выложил: …». Выкладывать может каждый участник с правом «черновики».

Песня с аккордами записывается в ChordPro — аккорды в квадратных скобках прямо в словах: `[Am]Ночь, бен[Dm]зин и ветер`. Припев — между строками `{soc}` и `{eoc}`, пояснение — `{c: текст}`; мелодию можно добавить в ABC-нотации. На странице каждая строка с аккордами — маленькая таблица в две строки: аккорд стоит над своим слогом при любом шрифте, без CSS3 и JavaScript, как и всё на сайте.

Править и удалять стих может тот, кто его выложил, сотрудник и `/u/0`.

У автора на сайте своя страница `/c/N`: его стихи и песни, книги, персонажи, фото и закреплённые обсуждения — форумы и доски. Профиль автора (имя, годы, описание, фото, обсуждения) правят сотрудники, `/u/0` и привязанные к нему участники. Фото и обсуждения есть и у участников, свой профиль участник правит сам на `/u/N/edit`. Фото проходит ту же обработку, что картинки книг, и стоит на странице в месте 240x320 по центру. Ещё — участник, который и есть автор: сотрудник или `/u/0` привязывает его на странице участника к одному или нескольким людям сайта («этот участник — Тютчев»), и тогда он распоряжается всем, что выложено от их имени, книгами тоже.

### Выложить книгу

Страница `/b/upload` принимает книгу текстом из формы или файлом. Форматов пять.

| формат | что из него берётся |
| txt | текст; главы — строки, начинающиеся с двух решёток |
| fb2 | описание, текст, картинки и обложка |
| epub | описание, порядок чтения, текст, картинки и обложка; защищённые файлы не открываются |
| pdf | только текстовый слой; экспериментально — только при запуске с -pdf |
| djvu | только текстовый слой; экспериментально — только при запуске с -djvu |

PDF и DjVu — экспериментальные форматы. Библиотека их не хранит и не отдаёт: из файла берётся текст, и книга дальше живёт текстом. Разбор этих форматов — самая тяжёлая и самая рискованная часть загрузки, поэтому его включают явно: флагами запуска -pdf и -djvu. Без флага формат не примет никто, что бы ни разрешала панель; в панели такой формат помечен «выключено». Сборка с -Dpdf=false или -Ddjvu=false не содержит разбора вовсе, и флаг становится неизвестным аргументом.

Что бы ни прислали, книга приводится к одному виду: название, автор, серия, год, аннотация и главы из абзацев. Из этого вида потом собираются скачивания.

### Картинки в книгах

Картинки берутся только из FB2 и EPUB; из PDF и DjVu — нет. Понимаются PNG, JPEG, GIF (первый кадр анимации), WebP (с потерями и без, с альфой, первый кадр анимации) и SVG. Растровая картинка уменьшается с сохранением пропорций так, чтобы влезть в место 800x600; маленькая не растягивается. Без прозрачности она сохраняется в JPEG качества 80 — так меньше, с прозрачностью — в PNG. SVG рисуется своим растеризатором сразу в своём размере, вписанном в место, и хранится PNG: фигуры, контуры, обводки, пунктир, градиенты и простые стили берутся, текст, фильтры и маски — нет. Разбор всех форматов, растеризация, уменьшение и запись написаны в программе заново, как и zstd; разбор сверен с декодерами Windows (GIF, WebP — совпадение бит в бит), SVG — с отрисовкой браузера.

На странице чтения картинка стоит своим абзацем в месте 800x600, а в узкой колонке место уменьшается, не меняя пропорций. Картинка вписана в него целиком и стоит по центру по обеим осям — и широкая, и высокая, и квадратная. Положение считает сервер в процентах места, поэтому раскладка держится и в старых браузерах, без CSS3. Под картинкой — подпись из книги. Обложка показывается на странице книги, в каталоге — нет.

Готовые картинки лежат в папке img/b/ (папку картинок можно задать флагом -img) под именем из отпечатка исходника. Снимок каталога хранит только ссылки на них, поэтому его пересборка картинок не трогает: картинка обрабатывается один раз, при первой сборке, где её книга встретилась, а одинаковые картинки разных книг лежат одним файлом. Картинки, на которые не ссылаются ни текущий, ни предыдущий снимок, убираются. В скачиваниях txt, fb2 и epub картинок нет.

Отказы объясняются словами. Скан без текстового слоя — «это картинки страниц, распознавания на сайте нет». PDF с паролем — так и сказано. PDF, в котором шрифт вложен без таблицы соответствия букв, — так и сказано. Сайт, который принял файл и показал вместо книги мусор, хуже сайта, который отказал и объяснил почему.

Команда `clipper convert ФАЙЛ` печатает то, что получится из файла, не запуская сервер: так проверяют книгу до того, как выкладывать.

### Записи: аудиокниги, чтецы и исполнители

Раздел `/v` — то, что звучит. Записи двух видов: аудиокнига — к книге библиотеки, исполнение — к стиху или песне из `/p`; у исполнения могут быть свои слова и ноты, если поётся не так, как записано. Текстовая основа необязательна: запись можно выложить без книги или стиха и связать позже в любом порядке — со страницы записи (привязать к уже выложенной или выложить книгу, текст прямо от неё) или со страницы книги, стиха (загрузить запись или привязать выложенную без основы). У каждой записи есть чтец или исполнитель — `/v/-N`. Участником сайта он быть не обязан; сотрудник или `/u/0` могут привязать к нему участника, как к автору, и тот правит записи чтеца. Чтецом может быть и сам автор: чтеца связывают с автором, его записи помечаются «(автор)», а на странице автора видно, что он читает своё.

У книги, стиха и записи можно указать источник — адрес или название: mrakopedia, arxiv, habr. Адрес показывается ссылкой с именем сайта.

| адрес | что откроется |
| /v | все записи и чтецы |
| /v/N | запись: проигрыватель, ссылка «скачать», слова и ноты исполнения |
| /v/N.mp3 | сам файл; отдаётся и кусками (Range), чтобы перематывать |
| /v/-N | чтец или исполнитель и его записи |

Принимается MP3 всегда, Ogg Vorbis — если сборка с -Dogg (по умолчанию да), M4A с AAC — с -Dm4a (по умолчанию нет). Что бы ни прислали, файл перекодируется в MP3 «как до 2003 года»: MPEG-1 Layer III, постоянные 128 кбит/с, 32, 44,1 или 48 кГц, тег ID3v1 в windows-1251 и никаких VBR, Xing и ID3v2 с картинками. Такой файл сыграет любой проигрыватель того времени, а на странице его заодно играет `<audio>` нового браузера. Разбор MP3, Vorbis и AAC и кодер MP3 написаны в программе заново; таблицы Хаффмана и окна сверены с ffmpeg, а результат — с декодером браузера: совпадение до шумов округления. Сборка с -Dvoice=false раздела не содержит вовсе.

### Скачать книгу

Любую книгу можно скачать в txt, fb2 и epub. Файлы не хранятся: они собираются по запросу из того же канонического текста, который показывает страница чтения. Поэтому они всегда соответствуют тому, что на сайте, и не занимают места. Скачивание поддерживает докачку.

## Разговоры: комментарии, форумы, доски

На сайте три вида разговора, и они различаются тем, сколько живёт сказанное.

### Комментарии к книге

Под книгой — комментарии. Отвечать можно на комментарий, но не на ответ: глубина — два уровня. Ответ на ответ уходит в ту же ветку. Это ограничение сделано нарочно: дерево глубиной в десять уровней на узком экране превращается в лесенку из трёх слов в строке, а спор двух человек занимает весь экран.

У комментария постоянный адрес: `/b/N/-1` — первый комментарий, `/b/N/-1-2` — второй как ответ на первый. Сервер проверяет связку: адрес `/b/N/-1-1` не откроется, потому что комментарий не может быть ответом сам себе. Ссылка, которая открылась, всегда описывает то, что есть.

### Форумы

`/f/1`, `/f/2` — обычные форумы: разделы, темы, сообщения по порядку. Всё остаётся навсегда. Это место для долгих разговоров, к которым возвращаются.

### Анонимные доски

`/f/b`, `/f/lit` — доски: писать может кто угодно, без имени, с картинкой. У каждой доски есть срок жизни нити — час, шесть часов, сутки. Когда срок выходит, нить исчезает целиком и без следа.

Это противоположность форума, и нужна она для того, для чего форум не годится: сказать необязательное. Разговор, который не останется, ведут иначе, чем разговор для архива. Библиотека, где можно только высказываться набело, выходит чопорной.

## Участники, права, панель

### Вход и сеансы

Регистрация — `/signup`, вход — `/signin`. Страница `/logout` — не просто кнопка: на ней список ваших сеансов с адресами, откуда они открыты, и возможность закрыть любой или все сразу. Если вы вошли с чужого компьютера и забыли выйти, это исправляется с любого другого.

Пароли хранятся хешами Argon2id. Сеанс — случайное значение в cookie; на сервере лежит только его хеш, так что по содержимому хранилища войти нельзя. Все формы защищены от подделки запроса.

### Шесть прав

У участника шесть прав, и каждое включается отдельно.

- **форум** — писать на форумах;
- **комментарии** — комментировать книги;
- **черновики** — вести черновики и статьи;
- **цитаты** — делать цитаты;
- **выкладывание** — выкладывать книги;
- **сотрудник** — всё, что может `/u/0`: панель сайта, правка и удаление чужого, привязка участников к авторам, профили авторов.

Новый участник получает первые четыре. Остальные выдаёт сотрудник или `/u/0`.

У `/u/0` перед сотрудниками одна привилегия — права сотрудников. Право «сотрудник» выдаёт и снимает только `/u/0`; прав `/u/0` не отнять никому, включая его самого. Сотрудник меняет права остальным участникам, но не себе и не другим сотрудникам: их строки в таблице прав для него только для чтения.

### Встроенный администратор

`/u/0` — одна встроенная учётная запись. Её вход задаётся флагами запуска: `-l` — логин (по умолчанию admin), `-pwd` — пароль открытым текстом или `-phc` — строка хеша Argon2id; вместе `-pwd` и `-phc` не задаются. Без пароля в `/u/0` не войти. Входить можно только с той же машины, где работает сервер.

Это не способ управлять сайтом каждый день, а способ его настроить: войти локально, дать кому-то право «сотрудник» — и дальше сайтом управляют сотрудники, откуда угодно. Встроенные книги, эта в их числе, числятся за `/u/0`.

Страница `/panel` для сотрудника и `/u/0` — пульт сайта.

- **Двенадцать переключателей.** Стихи, книги, цитаты, черновики, форумы, доски, выкладывание, комментарии, скачивание, встраивание, бейджи, регистрация. Выключенное исчезает из меню и отвечает 404. Переключатели могут только сузить то, что разрешили флаги запуска: раздел, выключенный флагом, в панели не показывается вовсе, а раздел «только для чтения» панелью не открыть на запись.
- **Права участников** — таблица: кто что может, кто заблокирован.
- **Оформление** — тема и режим по умолчанию, какие темы посетитель вправе выбрать сам, и видит ли он эту настройку вообще.
- **Форматы загрузки** — отдельно для сотрудников и для остальных.
- **Федерация** — список сайтов-соседей.
- **Форумы и доски** — завести новый форум (название, описание) или доску (адрес `/f/имя`, название, срок жизни нити). Других способов их завести нет.

Для остальных участников `/panel` — их собственные настройки.

## Разделы: какой сайт собрать

У Клиппера пять разделов, и у каждого своя буква: `p` — стихи и песни, `b` — книги (с закладками и выкладыванием), `d` — черновики и статьи, `f` — форумы и анонимные доски, `q` — цитаты, люди и персонажи. Участники, поиск, встраивание и бейджи есть всегда, но показывают только то, что открыто этому посетителю.

Четыре флага запуска решают, что с каждым разделом можно делать. За флагом — буквы разделов слитно.

| флаг | что значит | гость | участник | модератор |
| (нет) | всё открыто | читает | читает и пишет | читает и пишет |
| -M | пишут только модераторы | читает | читает | читает и пишет |
| -R | только чтение для всех | читает | читает | читает |
| -G | открыто гостям, прочее — после входа | читает | — | — |
| -N | раздела нет вовсе | 404 | 404 | 404 |

Модератор — участник с правом «сотрудник» и сам `/u/0`. `-R` сильнее `-M`. `-G` — список, а не прибавка: если он задан, гость видит только перечисленные разделы, а остальные исчезают для него из меню, главной и поиска; прямой адрес закрытого раздела ведёт на страницу входа. Ошибки в сочетании — буква из `-N` в другом флаге, повтор буквы, неизвестная буква — останавливают запуск одной понятной строкой.

Из пяти букв получаются разные сайты, и у каждой из четырёх тем для них своя главная — в полной и в мобильной версии:

| сайт | флаги | главная |
| полная библиотека | — | всё сразу |
| песенник | -Nbdfq | стихи по первой строке, песни с аккордами отдельно |
| читальня | -Ndfpq -Mb | новинки, серии, авторы |
| читальня с цитатами | -Ndfp | новинки и крупная цитата дня |
| форум | -Nbdpq | таблица форумов, ниже доски |
| цитатник | -Nbdfp | цитата дня, люди и персонажи, свежие цитаты |
| мастерская | -Nbq | свежие черновики и статьи, обсуждения |

Раскладка темы при этом не меняется — меняются меню и главная. Тексты в шапках тоже собираются из включённых разделов: песенник не называет себя библиотекой, а форум не зовёт искать книги. Цитатник — особый случай: книги в нём скрыты, но цитата ведёт «к месту в книге», и книга открывается только на чтение.

Почему флаги, а не только панель: флаг — решение того, кто запускает сайт, и оно не зависит от данных. Панель хранит выбор в хранилище записей, и его можно изменить на работающем сайте; флаг задаёт потолок, выше которого панель не поднимет. Сайт, запущенный как форум, не станет библиотекой оттого, что кто-то щёлкнул переключателем.

## Оформление: четыре темы, три режима

### Темы

У сайта четыре оформления: `flibusta`, `samlib`, `proza`, `nepomn`. Каждое повторяет устройство настоящего сайта начала двухтысячных: где меню, где поиск, как выглядит список. Это не четыре набора цветов, а четыре разные раскладки страницы.

Тема выбирается параметром адреса `t`, и он сохраняется при переходах: открыв `/b/2?t=samlib`, вы останетесь в этой теме, куда бы ни пошли. Ссылку с темой можно переслать, и получатель увидит то же, что и вы. Настройка не лежит в cookie, поэтому она работает и без них.

### Режимы

К теме добавляется режим: `-light`, `-dark`, `-time`. Без суффикса тема следует настройке устройства. `samlib-dark` — всегда тёмная. `samlib-time` — светлая днём и тёмная ночью, по часам сервера.

Цвета отделены от разметки. Страница не знает, какой у неё режим: она ссылается на файл стилей `/css/samlib-dark.css`, а в нём — переменные с цветами. Поэтому разметка одной темы одинакова для всех режимов и кэшируется один раз.

### Мобильная версия

Параметр `m=true` включает мобильную раскладку: одна колонка, крупный текст, колонки с меню уезжают вниз. Без параметра сервер решает по заголовку браузера. Параметр, как и тема, протягивается по ссылкам.

### Страница настройки

Всё это собрано на странице `/theme`. Она помнит, откуда вы пришли, и возвращает туда же в новом оформлении.

## Встраивание, бейджи и соседи

### Встраивание

Почти любую вещь с сайта можно показать на другом сайте через iframe: карточку книги `/e/b/N`, главу, стихотворение, цитаты человека, страницу автора, форум, счётчики сайта, баннер. Страница `/e` показывает всё это вживую и рядом — код, который надо скопировать. На странице каждой книги есть готовая строка для вставки.

### Бейджи

Адреса вида `/x/b/reads.svg?id=0` отдают маленькую картинку со счётчиком: сколько раз книгу прочли, сколько у неё комментариев, сколько книг у автора. Без расширения приходит JSON, с `.png` — растровая картинка для мест, где SVG не показывают. Подпись и цвет задаются параметрами.

Встраивание и бейджи — это то, чем сайт присутствует за своими пределами: в блоге автора, в подписи на форуме, на странице его друзей.

### Федерация

Несколько сайтов на Клиппере могут доверять друг другу. Участник одного сайта входит на другой под своим именем — без регистрации и без пароля. На странице `/fed` он нажимает «перейти», и оказывается на соседнем сайте гостем с именем вида «имя@сайт».

Внутри это устроено так, чтобы пароль не покидал своего сайта. Первый сайт выписывает одноразовый билет, живущий две минуты, и отправляет браузер к соседу. Сосед сам спрашивает первый сайт, настоящий ли билет, и получает в ответ номер и имя участника. Билет после этого погашен.

Гость с соседнего сайта — участник с ограничениями: у него нет пароля, его сеанс гаснет через 45 минут бездействия, и дальше по федерации он не идёт. Кому из соседей можно входить сюда и на кого можно ходить отсюда, решает администратор — таблицей в панели или файлом `FEDIVERSE.csv`, который можно править при работающем сервере.

### Для того, кто запускает сайт

Весь запуск — одна команда: `clipper -p ПОРТ`. Порт обязателен; всё остальное имеет значения по умолчанию.

| флаг | что делает |
| -r ПАПКА | папка библиотеки; по умолчанию текущая |
| -t ТЕМА | оформление для тех, кто не выбрал своё |
| -d РЕЖИМ | светлая (false), тёмная (true), по устройству (auto) или по часам (time) |
| -c ЦВЕТ, -b ЦВЕТ | главный и фирменный цвета: оттенки всех тем пересчитываются от них |
| -ico ФАЙЛ, -png ФАЙЛ | свой значок и свой логотип вместо встроенных |
| -M, -R, -G, -N РАЗДЕЛЫ | что можно делать с разделами (см. «Разделы») |
| -s АДРЕС, -n НАЗВАНИЕ | адрес и название сайта в шапках |
| -btree | хранить записи в B+ дереве, а не в журнале |
| -img ПАПКА | папка картинок (книг — в ПАПКА/b, досок — в самой папке); по умолчанию ROOTDIR/img |
| -zstd [N или ФАЙЛ] | сжимать кадры каталога своим zstd со словарём из файла clipperN.zstd |
| -pdf, -djvu | разрешить загрузку PDF и DjVu (экспериментально) |
| -w N | сколько процессов обслуживает сайт |
| --tls-cert, --tls-key | отвечать по https |
| -fed | включить федерацию |
| -l, -pwd, -phc | вход встроенного администратора /u/0 |

Язык интерфейса выбирается при сборке: `zig build -Dlang=en` даёт английский сайт со встроенными книгами на английском. Перевод — каталог `src/t9n/en.t9n`: строка исходника и её перевод; на работающем сервере перевода нет вовсе, строки подставляются при компиляции.

При первом запуске сервер создаёт папки и собирает каталог. Свежий сайт пуст: в нём только встроенные книги (`-Dbook0`, `-Dbooks`) и администратор `/u/0`. Ни стихов, ни участников, ни персонажей, ни форумов в программе нет. Форумы и доски заводит `/u/0` в панели, остальное пишут участники и приносит папка `books/`. Если флаг написан неверно, сертификат не подходит или файл настроек испорчен, сервер не стартует и пишет одну понятную строку. Сервер, который запустился с половиной настроек, опаснее сервера, который отказался запускаться.

В папке библиотеки всё лежит открыто: `books/` — исходные книги, `library.N.snap` — снимок каталога, `clipper.journal` — записи участников, `files/` — файлы, которые сайт раздаёт. Резервная копия сайта — копия этой папки. Переезд на другую машину — тоже.
